# EVIL

> [!CAUTION]
> This is in work in progress!
> All code in this repository should be considered unstable and/or incomplete until an official release is made.

# Executive Summary
Evil is a dynamic go code generator meant to provide some form of meta-programming to go by directly evaluating go code to:
- init or create _top level_ `var`s
- create _top level_ `const`s
- create any arbitrary go code
